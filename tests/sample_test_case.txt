====================================================================
               PROJECT SETUP & INSTALLATION GUIDE
====================================================================

Welcome to the project! Follow the steps below to setup your environment.

1. Prerequisites:
   - Ensure Python 3.10 or higher is installed.
   - Ensure Node.js 18+ is installed on your machine.

2. Installing Python Dependencies:
   To install all necessary Python packages for this application, 
   execute the following command in your terminal:

   pip install -r requirements.txt

3. Building Project Assets:
   To compile and package the frontend assets, run:

   npm install
